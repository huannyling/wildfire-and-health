# Dryad Metadata Draft

## Title

Derived data supporting Persistent gaps in wildfire-health evidence for vulnerable populations

## Description

This dataset contains minimally sufficient derived data supporting a multilingual audit of wildfire-health evidence gaps involving vulnerable populations. It includes structured labels for 525 LLM-confirmed wildfire-health studies, aggregate language counts, country-level research-to-fire-activity mismatch results, attribution-rule sensitivity analyses, and aggregate bilingual human-validation metrics. The deposit excludes full bibliographic retrievals, article titles and abstracts, prompt payloads, and intermediate screening files.

## Keywords

wildfire; wildfire smoke; health equity; vulnerable populations; evidence gaps; systematic mapping; large language models; climate adaptation; research-to-fire-activity mismatch

## Methods

See README.md and the associated manuscript. The dataset is derived from OpenAlex records retrieved for 2000–2024 using seven query languages. Controlled labels were generated through the prespecified screening and structured extraction workflow described in the manuscript.
